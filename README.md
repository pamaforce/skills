# veFaaS Skills

Agent Skills for building on Volcengine veFaaS platform.

## Installation

### NPX

```bash
npx skills add vefaas-dev/skills
```

### Manual

Clone this repository and copy the skill folders to your agent's skill directory:

| Agent | Directory |
|-------|-----------|
| Claude Code | `~/.claude/skills/` |
| OpenCode | `~/.config/opencode/skill/` |
| OpenAI Codex | `~/.codex/skills/` |
| Trae | `~/.trae/skills/` |

## Skills

| Skill | Description |
|-------|-------------|
| `vefaas` | Deploy and manage serverless applications on Volcengine veFaaS |
